# Getting Started

## Goal

Run the app locally and confirm the frontend can talk to the Go backend.

## Setup

- Node.js dependencies installed from the repo root.
- Go toolchain installed and available on `PATH`.
- Two terminals available, one for the frontend and one for the backend.

## Steps

1. Install frontend dependencies from the repository root.
2. Start the backend API from `backend/`.
3. Start the frontend dev server from the repository root.
4. Open the app in the browser.
5. Confirm the map shell loads and the status banner shows backend metadata.

## Checkpoint

You should see the boundary explorer shell, the layer list, the map stage, and a feature inspector panel.
