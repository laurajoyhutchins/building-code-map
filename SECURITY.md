# Security

Please report security issues privately rather than opening a public issue when disclosure could expose users, credentials, private project data, or service infrastructure.

This public repository contains interface contracts, methodology, synthetic fixtures, and open-source components. It does not contain production credentials or the maintained production regulatory corpus. If you believe private material has been published here accidentally, treat that as a security issue and include the affected path and commit in your report.

Do not include secrets, customer information, or non-public regulatory research in public issue reports.
